## 📤 Submission Steps

### Step 1: Create App in Play Console

1. Go to [Google Play Console](https://play.google.com/console)
2. Click **Create app**
3. Fill in:
   - App name: **Flicklet**
   - Default language: **English (United States)**
   - App or game: **App**
   - Free or paid: **Free**
   - Declarations: Check all applicable boxes

### Step 2: Complete Store Listing

1. Go to **Store presence** → **Store listing**
2. Fill in all required fields using content above
3. Upload feature graphic
4. Upload screenshots (minimum 2)
5. Add privacy policy URL: `https://flicklet.netlify.app/privacy.html`

### Step 3: Complete Policy Requirements

1. Go to **Policy** → **App content**
2. Complete **Content rating** questionnaire (use guide above)
3. Complete **Data safety** form (use guide above)
4. Complete **Target audience** section

### Step 4: Configure Subscriptions (Before Building)

1. Go to **Monetize with Play** → **Products** → **Subscriptions**
2. Create a subscription for Flicklet Pro with monthly and yearly base plans:
   1. Create a subscription:
      - Subscription ID: `flicklet_pro`
      - Name: "Flicklet Pro"
      - Description: "Unlock advanced notifications, unlimited lists, bloopers & extras, and more"

   2. Add base plans for regular pricing:

      **Regular Pricing:**
      - Base plan ID: `pro_monthly`
        - Billing period: Monthly
        - Price: **$2.99/month**
      - Base plan ID: `pro_yearly`
        - Billing period: Yearly
        - Price: **$19.99/year** (saves ~44% vs monthly)

   3. Configure introductory offers for founders pricing (limited to the first 90 days after launch):

      **Founders Launch Pricing (Limited-Time Offer - 90 Days After Launch):**
      - For `pro_monthly` base plan, create an offer:
        - Name: "Founders Monthly"
        - Effective price: **$1.99/month**
        - Availability: limited to the first 90 days after launch
      - For `pro_yearly` base plan, create an offer:
        - Name: "Founders Yearly"
        - Effective price: **$14.99/year** (saves ~37% vs founders monthly)
        - Availability: limited to the first 90 days after launch

   4. Save and activate the subscription, base plans, and founders offers.
   5. Make sure the subscription IDs and base plan/offer IDs match what your app expects in code (see `GOOGLE_PLAY_BILLING_IMPLEMENTATION.md`).

### Step 5: Build and Upload APK/AAB

1. Build release APK/AAB:
   ```bash
   npm run mobile:build
   cd android
   ./gradlew assembleRelease
   # Or for AAB:
   ./gradlew bundleRelease
   ```
2. Go to **Production** → **Create new release**
3. Upload APK or AAB file
4. Add release notes (what's new in this version)

### Step 6: Submit for Review

1. Review all sections for completeness
2. Click **Submit for review**
3. Wait for Google's review (typically 1-7 days)
